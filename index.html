What is Cache Memory?

Cache memory is a small and fast memory located close to the processor. It stores frequently used data so that the CPU can access it faster.

Fast Access

Reduces memory access time.

Better Performance

Improves CPU performance.

Temporary Storage

Stores frequently accessed data.

Cache Mapping Techniques

Direct Mapping

Each memory block maps to one fixed cache line.

Fully Associative

A memory block can be placed in any cache line.

Set Associative

A memory block maps to a set and can occupy any line in that set.

Memory Hierarchy

Registers

Fastest storage inside the CPU.

Cache Memory

Stores frequently used data.

Main Memory (RAM)

Stores currently running programs and data.

Secondary Storage

Stores data for long-term use.

Worked Example – Direct Mapping

Assume the cache contains 4 cache lines.

Memory blocks: 0, 4, 8

Formula: Cache Line = Block Number % Number of Cache Lines

Memory Block Calculation Cache Line
0 0 % 4 0
4 4 % 4 0
8 8 % 4 0

Observation: All three memory blocks map to cache line 0. Therefore, they replace one another when accessed in sequence.
